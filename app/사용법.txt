판매도구 사용법 (통합)
======================
msgood4u 상품번호만 넣으면 키워드 → 상품명 → 가격 → 대표·추가이미지 → 카테고리까지 초안을 만들고,
검토 후 [등록]을 누르면 #1 #2 #3 계정의 스마트스토어·쿠팡에 올립니다. 하루 20개까지 대기열에 쌓아 두면 하나씩 차례로 만듭니다.

[처음 한 번]
1. api_keys.json 에 키 넣기 ([설정] 탭 → [키 파일 열기])
   - #1 계정: naver_commerce, coupang
   - #2 계정: naver_commerce_2, coupang_2   /  #3 계정: naver_commerce_3, coupang_3
   - 키워드 검색량: naver_searchad
2. [설정] 탭에서 계정마다 [사용] 체크, 틀 상품번호(네이버 상품번호 / 쿠팡 상품ID) 넣고 [저장]
   - 틀 상품: 그 계정에 이미 올린 상품 하나. 배송·반품·A/S·공지 설정을 그대로 복사합니다.
   - 개수: #1 스토어 1,2 / 쿠팡 1,3,5   #2 스토어 1,2 / 쿠팡 2,4,6   #3 스토어 1,2 / 쿠팡 1,2,3
3. [msgood4u] 탭에서 로그인 (도매가·배송비를 읽는 데 필요. 로그인 상태는 저장됩니다)

[매일]
1. 위 칸에 msgood4u 상품번호를 넣고 Enter (여러 개는 띄어쓰기·쉼표로)
2. 상품마다 약 3~4분 동안 자동으로 만듭니다 (왼쪽 목록의 상태가 "진행 중 n/6")
   ① msgood4u: 상품명·브랜드·판매가·도매가·배송비·판매 조건
   ② 상세 페이지 글자 읽기 (주 키워드·키워드·"상품에 있는 말인지" 판단에 씀)
      카테고리: 상세 페이지 주 키워드(상품 이름 중 상세에 가장 많이 나온 말: 유산균·흑삼·젖산마그네슘)로 네이버 쇼핑을 검색해
                상품들 카테고리 중 가장 많은 것. 건강기능식품 표시가 있으면 건강식품 쪽 카테고리 우선.
                쿠팡은 주 키워드 + 네이버 카테고리 이름으로 예측 (유산균 프로바이오틱스)
      - msgood 상품명 맨 끝 단어(상품 종류)와 그 뒷부분으로 네이버 쇼핑을 검색해 상품들 카테고리 중 가장 많은 것
        (예: 발효흑삼고 → 흑삼고 → 식품>건강식품>홍삼>홍삼액)
      - 시작 단어도 그 검색 결과 상품명에 많이 나온 말 중에서 고름 (예: 발효 X → 흑삼)
   ③ 시작 단어 (상세 페이지 주 키워드)
      - 상품 종류 단어(msgood 상품명 맨 끝, 예: 젖산마그네슘·오트밀)가 월간검색량 1,000 이상이고 상세 페이지에 3번 이상 나오면 그 단어
      - 아니면 그 단어 속 상품 이름 부분(발효흑삼고 → 흑삼, 슬림다이어트앤유산균 → 유산균) 중 상세 페이지에 가장 많이 나온 말
        (맨 앞 꾸밈말 발효·슬림 등은 제외, 검색량 1,000 이상, 네이버 쇼핑 검색 결과 상품명 70% 이상에 나오는 말)
      - 키워드에는 상세 페이지에 2번 이상 나온 말도 넣음 (예: 글루콘산·장건강). 단 이 카테고리 상품명에도 쓰이는 말만
      - 카테고리 확인: 상품명에 넣을 만한 단어는 하나씩 네이버 쇼핑에서 검색해, 결과 상품들이 이 상품 카테고리인지 봄
        (예: 프로바이오틱스 상품에 비타민D·가르시니아·체지방감소는 다른 카테고리라서 안 씀. 검토 화면 비고에 "다른 카테고리 n%")
      - 그 단어로 검색했을 때 브랜드 목록에 똑같이 나오면 브랜드로 뺌
      - 시작 단어의 오타(젓산마그네숨·젓산마그네슘)는 검색량이 있으면 상품명 앞쪽에 꼭 넣음 (경쟁 상품이 적어서)
      키워드: ②에서 정한 네이버 카테고리 안에서 가격비교 1페이지 상품명의 단어 → 월간검색량 → 상품총수량
      (예: 오트밀 카테고리 안에서 찾으므로 "오버나이트"로 생리대가 나오지 않음. 1페이지에 2번 이상 나온 단어만)
      - 브랜드는 자동으로 뺌: 가격비교 브랜드 목록, msgood 브랜드, 잘 알려진 브랜드(정관장·종근당·유한양행·코스트코 등),
        회사 이름 모양(…제약·…양행·…웰빙·…닷컴), 학습한 브랜드. 인물 이름(네이버 프로필이 나오는 이름)도 뺌
      - mg·ml 같은 단위, 네이버·단독·특가 같은 판매 문구는 키워드로 안 씀
      - 상품명에는 이 상품의 상품명·상세에 따로 쓰인 말이거나 1페이지 40개 중 10개 이상에 나온 말만 (다른 원료 이름이 섞이지 않게)
        (말차바나나·치아씨앗 속의 바나나·치아는 따로 쓰인 말로 보지 않음)
      - 숫자 주장(100억 등), 여성·남성, 비타민D 같은 영양성분, 포스트바이오틱스 등은 상세 페이지에 있어야 씀
        (여성·남성은 "미국 여성 89명" 같은 인용 말고 2번 이상 나와야)
      - 골라담기·냉장고·프리미엄 같은 말, 8자 이상 붙은 상품 이름(슬림다이어트앤유산균 등)은 안 씀
      - 소형키워드(상품총수량 < 2 × 월간검색량)를 먼저, 위의 [키워드 순서]대로 (검색량 순 / 배율 순 / 상품총수량 적은 순)
   ④ 상품명: 스토어 50자, 쿠팡 100자. 계정·개수마다 단어 배열을 다르게
      - 키워드가 모자라면 검색광고 연관 키워드(예: 오버나이트오트밀·귀리오트밀)로 채움
        (시작 단어를 뺀 나머지가 1페이지 상품명이나 msgood 상품명에 나온 말일 때만. 오트밀크·오트밀죽·효능·칼로리 같은 말은 안 씀)
      - 쿠팡은 상세 페이지에 나온 맛 이름(무화과맛 …)과 구성·용량(6종 세트 50gx12포)까지 넣어 100자 가까이
      가격: 가격설정기 식 (원가 = 도매가). 단 아래 하한선 × 개수 밑으로는 안 내려감
        - "스마트스토어,쿠팡 ○○원이상" 이 있으면 그 금액
        - "[판매가 절대 준수]" 만 있으면 msgood4u 판매가
   ⑤ 상세 이미지에서 용량·섭취방법 읽기
   ⑥ 대표이미지 1~6통, 추가이미지 4장
   [쿠팡 검색어] 상품명에 쓰면 안 되는 단어를 시작 단어와 붙여, 쿠팡 검색창 자동완성에 실제로 나오는 검색어로 (최대 20개)
      - 예: 아기 → "아기 오트밀", 그래놀라 → "오트밀 그래놀라", 오나오 → "오나오 오트밀" (단어 하나만 넣지 않음)
      - 대상 단어: 월간검색량 1,000 이상인 것만 ([설정] 탭에서 바꿈)
        · 브랜드: 가격비교 브랜드 목록, 학습한 브랜드(오나오·퀘이커·두리두리 등)
        · 위험 단어: 아기·유아·영아·어린이·임산부·이유식 등
        · 상품에 적혀 있지 않은 말: 유기농·국산·무설탕·대용량 등
        · 상품 형태가 아닌 말: 파우더·가루·분말·액상·마시는·스틱·캡슐·시리얼·그래놀라·포리지 등
          (상품명·상세 페이지에 그 말이 따로 쓰였는지로 판단. 요거트분말·녹차가루처럼 원료 이름 속의 말은 인정 안 함)
      - 검색어 중심은 상품 종류 단어(상품명 맨 끝, 예: 오트밀). 검색어의 모든 낱말이 상품 종류 단어·고른 단어·이 카테고리 상품명에 나온 말이어야 함
        (예: 오버나이트 → 생리대·기저귀 검색어는 안 들어감)
      - 검토 화면 [쿠팡 검색어] 칸에서 고칠 수 있고, [쿠팡 검색어 다시 찾기]로 다시 만듦
      - 쿠팡 검색어는 상품등록 화면에는 없고 상품조회에 나오므로, 등록 마지막 단계에서 임시저장된 쿠팡 상품을 다시 열어
        검색어가 비어 있으면 넣고 저장합니다 (결과 줄에 "쿠팡 검색어 n개 저장")
   ※ 프로그램이 네이버 쇼핑·쿠팡을 읽는 화면은 왼쪽 아래 [작업 화면]에 늘 보입니다 (오른쪽 검토 화면은 그대로).
     "보안 확인" 이 나오면 작업 화면에서 풀어 주세요. [크게]를 누르면 크게 보입니다.
3. 상태가 "검토 대기" 가 되면 목록에서 눌러 확인·수정
   - 키워드 체크를 바꾸고 [체크한 키워드로 상품명 다시 만들기]
   - 시작 단어나 네이버 카테고리 칸을 바꾸면 프로그램이 알아서 키워드·상품명·쿠팡 검색어를 다시 찾음 (대기열, 상태 "대기 (키워드)")
     [키워드 다시 찾기]·[쿠팡 검색어 다시 찾기] 버튼도 대기열에 들어가서, 다른 상품을 만드는 중이어도 눌러 두면 차례로 함
   - 상품명·가격·카테고리는 칸에서 바로 고침
   - 이미지를 누르면 크게 보임. 이미지를 바꾸려면 [폴더 열기] 에서 같은 이름으로 덮어쓰기
4. [등록] → 결과가 아래에 나옴
   - [설정]의 "네이버는 판매중지 상태로 등록" 이 켜져 있으면 스마트스토어센터에서 확인 후 판매 시작
   - "쿠팡은 승인요청까지" 가 꺼져 있으면 윙에서 임시저장 상품을 승인요청

[규칙이 바뀌면]
프로그램을 고쳐 상품명·키워드 규칙이 바뀌면, 등록 전인 "검토 대기" 초안은 켤 때 알아서 새 규칙으로 다시 만듭니다.

[학습]
검토 화면에서 고친 내용은 [등록]할 때 기억해서 다음 상품부터 반영합니다.
  - 상품명에서 뺀 단어 → 다음부터 뺌 / 직접 넣은 단어 → 다음부터 앞쪽에
  - 시작 단어를 바꿈 → 비슷한 상품명에서 같은 단어
  - 카테고리를 바꿈 → 같은 msgood4u 카테고리면 같은 카테고리
[학습 내역] 탭에서 배운 규칙을 보고, 잘못 배운 건 지울 수 있습니다.

settings.json(설정), learned.json(학습), api_keys.json(키 - 다른 사람에게 보내지 마세요)
