# SalesTool (판매도구)

이커머스 셀러를 위한 건강기능식품 자동 상품명 생성, 쿠팡/스마트스토어 맞춤 검색어 풀링, 대표이미지 합성 및 다중 사업자 관리 자동화 도구입니다.

## 주요 기능
- **쿠팡 3개 샵 맞춤형 전자동 풀링**:
  - 쿠팡 #1: 질병/의약품 위험 키워드 우선 주입 (월간검색수 > 30)
  - 쿠팡 #2: 인물 키워드 우선 주입 (월간검색수 > 30)
  - 쿠팡 #3: 트렌드 급상승 키워드(최근 증가배수▲) 우선 주입 (월간검색수 > 30)
  - 20개 미달 시 상품명 안전 단어를 제외한 선을 넘나드는 실전 키워드로 20개 무조건 100% 자동 완결
- **대표이미지 자동 합성 (1~6통 수량 배지 & 네이버 대표)**:
  - Aside AI 브라우저 및 챗GPT 유료 계정 연동 프롬프트 복사 & 클립보드 즉시 붙여넣기(Ctrl+V) 지원
- **스마트폰 모바일 웹 & 알림 연동**:
  - 와이파이 / Tailscale 기반 휴대폰 앱 연동
  - 초안 작성 시 알림 선택 옵션 및 발주/품절 알림
- **다중 사업자 분리 지원**:
  - 사업자별 msgood4u 로그인 분리, 독립 상품명 및 자동 발주 연동

## 빌드 방법 (Windows)
Visual Studio 없이 번들된 Roslyn C# 컴파일러로 즉시 빌드할 수 있습니다.

1. 저장소를 클론합니다:
   ```cmd
   git clone https://github.com/softmaxman-wq/SalesTool1.git
   cd SalesTool1\app
   ```
2. `build.bat`을 실행합니다:
   ```cmd
   build.bat
   ```
3. `app\build\SalesTool.exe` 및 의존성 라이브러리가 생성됩니다.

## 설정 파일 (api_keys.json)
`api_keys.example.json`을 참고하여 실행 파일과 같은 디렉터리에 `api_keys.json`을 생성하고 필요한 키를 입력하여 사용합니다.
- `naver_searchad`: 네이버 검색광고 API 키 (월간검색수 조회용)
- `naver_datalab`: 네이버 데이터랩 트렌드 API 키
- `telegram`: 발주/품절 텔레그램 알림 봇 토큰
- `github`: 프로그램 자동 업데이트 확인용 GitHub 토큰 (선택)
